## Not tried / next

1. **Hot Pepper HL13 pages 5→N.** Only pages 1–4 of 24,574 were mined. Same recipe (`&pn=N`, then rebuild image URLs from the B-numbers) scales indefinitely; pages 5–15 would add ~400 more.
2. **Hot Pepper style-detail pages** `/catalog/style/L#########.html` — these carry the **stylist name, menu price and a longer style description**, none of which were captured here (this pass recorded the salon only). The `L`-ids sit next to each image on the list pages; capture them in the same JS pass next time.
3. **Hot Pepper model-attribute filters**, never used: `顔型 = 卵型` (oval face) plus 髪質 / 太さ / クセ are checkboxes on `/CSP/bt/hairCatalogSearch/mens/`. Filtering HL13+perm by 卵型 would target the user's face shape directly.
4. **Hot Pepper keywords not yet run**: `セミロング`, `マッシュロング`, `ウルフロング`, `ロン毛`, `韓国風ロング`, `センターパートロング`, `波巻き` (alone), `スパイラルパーマ` (alone), `くびれ`, `外ハネ`, `平成`, `90年代`, `ソバージュ`, `ヒッピーパーマ`.
5. **Video thumbnails**: the HL13+perm list pages also carry `imgbp.hotp.jp/video/thumb/MVB########/…_THUMB.jpg` entries (motion catalogues showing a style from several angles). Deliberately skipped this pass; they are a good "360°" substitute.
6. **OZmall pagination** — every category page was read at depth 1 only; OZmall paginates and would roughly double the 503 unique images.
7. **GOALD / ALBUM / kamimado** need the user's Chrome rather than curl (curl gets exit 000 — likely TLS fingerprinting or UA/geo gating). Worth one Chrome pass each.
8. **OCEAN TOKYO / Lond / MINX / AFLOAT / ANTI / Dot+LIM** are all JS-rendered SPAs — they need Chrome + `javascript_tool`, not curl.
9. **mensnonno.jp 360° catalogue** — only incidental article images were captured via Bing. `mensnonno.jp/post_360/` was read in the previous pass but never image-harvested.
10. **Google Images** was not used (Bing alone gave clean `murl` extraction, and other agents were occupying the Google tabs). A Google Images pass on the same three queries would surface a different tail.
11. **Higher-resolution OZmall**: 360×480 is the public ceiling; the per-style page `/hairsalon/<salonId>/catalog/<catalogId>/` was checked and serves the same file.
12. **Duplicate suppression across salons**: several salons (Altn men's hair, Bee dandy, kusyu…, the fifth chain, RESSUΛL) re-post near-identical photos under many style names. A perceptual-hash dedupe over `images/jp/` would trim perhaps 30–50 near-duplicates.
